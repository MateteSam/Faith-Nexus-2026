Add small page-turn sound files here if you want audio feedback when flipping pages.

Recommended filenames:
- page-turn.mp3  (a soft paper flip sound, ~200-400ms)
- page-click.mp3 (optional small click for controls)

Place the files at:
/public/sounds/page-turn.mp3
/public/sounds/page-click.mp3

The app will automatically try to play page-turn.mp3 when a page flips. If no file is present, the UI remains silent.
